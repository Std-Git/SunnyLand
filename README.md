# SunnyLand
- Game Type: 2D Platformer
- Control:
1.Move by WASD or the Arrow Key  
2.Jump by Space or "J" Key  
3.Pause in game by "P" or the "ESC" Key  
- Code Language: C++  
- Tutorial from Bilibili ZiyuGameDev  
- [Tutorial Source Code: https://github.com/WispSnow/SunnyLand](https://github.com/WispSnow/SunnyLand)
